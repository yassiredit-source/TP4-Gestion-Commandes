# Gestion des Commandes - TP4
Application frontend structurée permettant de gérer et lier des données JSON (clients, produits, commandes).

**Structure**
- `index.html` : Interface principale
- `data/` : Fichiers JSON (customers, products, orders)
- `js/` : Modules JavaScript (app, view, selectors, state, dataService)

**Fonctionnalités**
- Chargement asynchrone des données
- Calcul des montants totaux
- Filtrage par client, statut et catégorie
- Affichage des détails via Modal

**Instructions**
Ouvrir `index.html` avec Live Server.
